# Success metrics

**Status: Planned.** No analytics are installed. Targets are proposals for the
project owner to confirm.

## North star

**Accepted exchange offers per month in Lancaster County** — contractors actually helping each other.

## Launch-phase metrics

| Metric | Definition | Proposed 90-day target |
| --- | --- | --- |
| Organizations | Organizations with a published profile | 100 |
| Activation | % of sign-ups that publish a profile within 7 days | 50% |
| Map coverage | Distinct trades with ≥ 3 published profiles | 10 |
| Requests posted | Open requests per week | 15 |
| Response rate | % of open requests receiving ≥ 1 offer within 48h | 60% |
| Match rate | % of open requests with an accepted offer | 30% |
| Retention | % of organizations active in month 2 | 40% |
