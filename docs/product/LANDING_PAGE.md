# Landing page

**Status: Implemented and tested locally (Milestone 2), not yet deployed.** `src/app/(marketing)/page.tsx`,
prerendered static. All planned sections below exist except the Open Graph image and analytics event.

## Goals

1. Explain Paradise in five seconds to a Lancaster County contractor.
2. Drive sign-ups.
3. Build trust (local, independent, real people).

## Planned sections

1. Hero — "Independent by Trade. Connected by Paradise.", one-line value, **Join Paradise** CTA, local imagery.
2. How it works — profile → get found on the map → trade help through the Exchange.
3. Network — map preview of the county.
4. Exchange — example requests (equipment, labor, materials, subcontracting).
5. Paradise Points — plain-language explanation; clear that transfers come later.
6. Built for Lancaster County — local launch story.
7. Future ecosystems teaser (Business, Media, Maestro).
8. Final CTA + footer.

## Requirements

Mobile-first, fast on rural LTE (no heavy hero video), accessible (AA), real copy (no lorem ipsum),
metadata and Open Graph image, analytics event on sign-up click ([SUCCESS_METRICS.md](SUCCESS_METRICS.md)).
