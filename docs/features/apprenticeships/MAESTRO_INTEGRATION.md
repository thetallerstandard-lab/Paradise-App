# Maestro integration

**Status: Planned (post-MVP).** No code.

Maestro is a **separate nonprofit organization** focused on apprenticeships,
mentorship and workforce development. Paradise connects contractors to it; it
does not run Maestro's programmes.

## Intended capabilities

- Contractors flag themselves as willing mentors / apprenticeship hosts.
- Apprentices discover host contractors by trade and location.
- Hours and milestones recorded for programme reporting.

## Boundaries to settle first

- Data sharing agreement between Paradise and Maestro (what contractor and apprentice data crosses over, consent).
- Minors: if apprentices may be under 18, additional privacy and safeguarding requirements apply.
- Whether Maestro has its own system (integrate by API) or uses Paradise directly (separate tenant/organization type).
