# network

Paradise Network: contractor profiles, trade categories, service areas, and the map.

- Tables: `contractor_profiles`, `contractor_profile_trades`, `trade_categories`, `service_areas`.
- Implemented: input validation schemas and Lancaster County bounds (`schemas.ts`).
- Planned (Milestone 2): profile editor, public profile page, Mapbox map with PostGIS proximity queries.
- Planned later: referrals, trust signals (licence/insurance verification).
